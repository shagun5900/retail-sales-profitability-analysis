# SQL Analysis

SQL scripts will be added after inspecting the actual source schema and selecting a suitable database or SQL engine.

## Planned analyses

- Row counts and data-quality checks
- Sales and profit aggregation by available dimensions
- Monthly trends
- Product/category performance
- Independent validation of dashboard KPI totals

## Standards

- Use explicit column names in final analytical queries.
- Comment on business logic and assumptions.
- Handle nulls and division by zero deliberately.
- Validate totals against source data and Power BI.
- Document the SQL dialect used.

Schema-specific queries are intentionally not included yet to avoid inventing table or column names.
