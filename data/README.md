# Data

This directory is reserved for project data or lightweight data documentation.

## Data handling

- Download the source data from the [Maven Analytics Data Playground](https://mavenanalytics.io/data-playground).
- Search for **Global Electronics Retailer**.
- Keep an untouched copy of the original files locally.
- Confirm dataset terms before committing or redistributing any data.
- Do not upload credentials, private files, or unrelated personal data.
- Record filenames, table names, row counts, date range, and any filters applied in the project documentation.

The source files are not included in this repository yet. The schema and file format will be inspected before writing schema-specific SQL or Power Query steps.
